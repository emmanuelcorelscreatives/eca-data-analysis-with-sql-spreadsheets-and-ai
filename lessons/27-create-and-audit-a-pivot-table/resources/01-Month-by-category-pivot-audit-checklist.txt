Before building: identify the sales-line grain, header row, last intended source row, numeric sales field, category field, and prepared reporting-month field. Record an independent source row count, blank-month count, blank-category count, and source sales sum. Check month assignments on dates near period boundaries. Build: select only source headers and data; place reporting month in Rows, category in Columns, and sales in Values; explicitly set Values to SUM; retain totals. Audit: compare pivot month and category labels with populated source values; hand-check selected month-category cells; add monthly totals and category totals separately; confirm both equal the independent source sales sum. If a check fails, inspect range coverage, field placement, month assignments, category spelling or blanks, and numeric value types before using the pivot.
