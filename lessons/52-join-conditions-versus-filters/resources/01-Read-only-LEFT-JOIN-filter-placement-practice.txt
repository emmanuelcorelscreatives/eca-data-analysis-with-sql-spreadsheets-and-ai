Run each statement separately. Expected order IDs are derived from the VALUES shown in the statements; confirm them in your own result grid.

Baseline — expected: 101, 102, 103, 104.
SELECT o.order_id, o.customer_id, c.customer_id AS matched_customer_id, c.status
FROM (VALUES (101, 1), (102, 2), (103, 9), (104, 3)) AS o(order_id, customer_id)
LEFT JOIN (VALUES (1, 'active'), (2, 'inactive'), (3, 'active')) AS c(customer_id, status)
  ON c.customer_id = o.customer_id
ORDER BY o.order_id;

Left-side condition in WHERE — expected: 102, 103, 104.
SELECT o.order_id, o.customer_id, c.customer_id AS matched_customer_id, c.status
FROM (VALUES (101, 1), (102, 2), (103, 9), (104, 3)) AS o(order_id, customer_id)
